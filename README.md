## 제가 중요하게 생각하는 것

- 문제를 데이터 분석이 가능한 형태로 구조화하는 과정
- 데이터 수집 → 전처리 → 모델링 → 평가까지 전체 분석 흐름
- 단순한 모델 성능보다 결과를 해석하고 설명하는 과정
- 분석 결과를 실제 사용 가능한 서비스로 연결하는 과정
- 팀 프로젝트에서도 개인 기여 범위를 명확하게 기록하는 것

## GitHub 활용 방식

이 GitHub는 단순히 코드를 저장하는 공간이 아니라,
